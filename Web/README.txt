Этот раздел описывает веб-часть проекта True Dota — статический сайт-путеводитель по мете Dota 2 (патч 7.40c), а также то, как фронтенд развёрнут на хостинге и взаимодействует с backend’ом и сторонними сервисами.

1. Общая идея фронтенда

Фронтенд True Dota — это сайт на чистых:

    HTML5 — разметка всех секций сайта;

    CSS3 — кастомный UI-кит (карточки, гриды, типографика, адаптив);

    JavaScript (script.js) — интерактивные компоненты, фильтры, окна, работа с формой.

Ключевые задачи фронтенда:

    красиво и удобно отрисовать мету 7.40c (герои, сборки, тир-лист);

    дать пользователю интерактивные инструменты: драфт-хелпер, мини-форум, голосование за героев/сборки;

    реализовать регистрацию и профиль через удобную форму;

    встроить Twitch и YouTube стримы в общий дизайн;

    работать как лёгкий статический сайт, который можно легко развернуть на любом хостинге.

2. Структура фронтенд-проекта

Базовая структура:

/
├── index.html      # Основной HTML (интерфейс)
├── styles.css      # Все стили (layout, компоненты)
├── script.js       # Клиентская логика и интеграции
└── images/         # Картинки (герои, мета, сборки, иконки)

2.1. index.html

Содержит полный каркас UI:

    Sidebar (<aside class="td-sidebar">)

        Лого (TD), название проекта True Dota, подзаголовок meta & community.

        Навигация по секциям (Главная, Мета, История патчей, Сборки, Топ героев, Тир-лист, Драфт-хелпер, Трансляция, Обсуждения, Регистрация, Профиль, О проекте).

        Блоки с текущим патчем и трендами по ролям.

        Компактный виджет пользователя («Гость» / статус), кнопка «Войти / Зарегистрироваться».

    Topbar (<header class="td-topbar">)

        Название и подзаголовок (Путеводитель по мете и обсуждениям (7.40c)).

        Поисковая строка по героям/сборкам/темам (планируется логика в JS).

    Основные секции (<section id="section-...">)

        section-home — герой-блок, CTA («Смотреть мету», «В обсуждения»), статусы (кол-во тем, сборок и героев).

        section-meta — сетка по ролям: Carry, Mid, Offlane, Supports (карточки с картинками и списком героев/особенностей).

        section-patches — таймлайн патчей, наполняемый через JS.

        section-builds — сетка сборок с фильтрами по ролям, стилю, длительности и сложности.

        section-heroes — топ героев с описаниями и голосованием.

        section-tierlist — drag & drop тир-лист (S/A/B/C).

        section-draft — драфт-хелпер (мой пик vs враги, подсказки по драфту).

        section-stream — Twitch + YouTube iframes.

        section-discussions — список тем, фильтр по тэгам, мини-форум.

        section-register — форма регистрации.

        section-profile — отображение профиля.

        section-about — краткое описание проекта.

    Модальные окна

        #newThreadModal — создание новой темы (заголовок, тэг, текст).

        #heroDetailsModal — подробная инфа по герою (сильные/слабые стороны, синергии, контры, пример сборки).

2.2. styles.css

Описание дизайн-системы и общих правил:

    Layout:

        двухколоночная структура: фиксированный sidebar + основной контент;

    Компоненты:

        .td-card, .td-btn, .td-chip, .td-tag, .td-list, .td-modal, .td-form, и т.д.;

        карточки меты и сборок, гриды героев и тир-листов.

    Цвета и типографика:

        темная тема, акцентные цвета для тэгов и кнопок;

        единый стиль заголовков и текста (H1–H4, body, подписи).

    Анимации и hover-эффекты:

        плавное появление блоков (td-reveal),

        hover на карточках и кнопках,

        визуальные подсказки для drag & drop зон.

2.3. script.js

Отвечает за интерактив:

    навигация (подсветка активного пункта sidebar при скролле);

    мобильное меню (открытие/закрытие сайдбара);

    счётчики (statThreadsCount, statBuildsCount, statHeroesCount);

    заполнение блока «Герой дня» (heroOfDayCard);

    фильтры сборок (по роли, стилю, длительности, сложности);

    голосование за сборки и героев (кнопки 👍 и обновление счётчиков);

    инициализация тир-листа (drag & drop);

    драфт-хелпер (добавление героев в «Моя команда» / «Враги», подсказки);

    работа с модалками:

        открытие/закрытие окна создания темы;

        открытие модалки героя с подробными данными;

    обработка формы регистрации:

        сбор данных из #registerForm;

        отправка запроса на backend;

        отображение статуса (#registerStatus);

        обновление UI профиля (nickname, email, rank, role, about).

3. Взаимодействие с backend’ом

Фронтенд устроен так, чтобы backend легко можно было заменить (Supabase, другой PHP-сервер, Node и т.п.), т.к. вся логика общения вынесена в JS.

Основные интеграционные точки:

    Регистрация
    Форма #registerForm отправляет данные (nickname, email, password, rank, role, about) на указанный в script.js endpoint. Ожидается JSON-ответ с результатом регистрации.

    Профиль
    После успешной регистрации фронтенд:

        отображает nickname/email в секции Профиль,

        обновляет виджет пользователя в сайдбаре («Гость» → никнейм, статус → авторизован).

    Обсуждения / темы
    Листинг тем (#threadsList) может получать данные из backend’а (через API), а форма создания темы (#newThreadForm) — отправлять POST запрос. Нынешняя верстка уже готова под асинхронное взаимодействие; реализация API — на стороне backend’а.

4. Стрим-интеграции (Twitch & YouTube)

В секции Трансляция используются два iframe:
4.1. Twitch

<iframe
    src="https://player.twitch.tv/?channel=stariy_bog&parent=true-dota.bestgastore.site&autoplay=true"
    frameborder="0"
    allowfullscreen="true"
    scrolling="no">
</iframe>
4.2. YouTube

<iframe
    src="https://www.youtube.com/embed/dnij9b-yFdw?autoplay=1&mute=1"
    title="Dota 2 Stream"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowfullscreen>
</iframe>

YouTube вписан в общий карточный дизайн, размеры и стили контролируются через .td-stream-frame в styles.css.

6. Дизайн: принципы и особенности

При проектировании интерфейса True Dota были заложены такие принципы:

    Фокус на мету и обсуждения, а не на «гайды для новичков»

        В тексте и структуре акцент на патч, роли, билды и комьюнити-дискуссии.

    Чёткий, модульный UI

        Весь экран разбит на логические блоки: мета, тир-лист, драфт, обсуждения, профиль.

        Карточки и гриды легко масштабировать и дополнять.

    Интерактивные элементы без перегруза

        drag & drop тир-лист и драфт-хелпер;

        голосование за героев/сборки;

        модалки для подробностей (герои, темы).

    Единый визуальный стиль

        консистентные карточки (.td-card), кнопки (.td-btn), тэги (.td-tag), чипы (.td-chip);

        темная палитра, подходящая под Dota-настроение;

    Готовность к расширению

        всё, что сейчас захардкожено (герои, сборки, патчи), легко заменить на данные из API;

        структура HTML уже подстроена под динамическую подгрузку в script.js.
