# TrueDota_FrontEnd
Цей розділ описує веб-частину проекту True Dota – статичний сайт-путівник за метою Dota 2 (патч 7.40c), а також те, як фронтенд розгорнутий на хостингу та взаємодіє з backend'ом та сторонніми сервісами.

1. Загальна ідея фронтенду

Фронтенд True Dota - це сайт на чистих: 

HTML5 - розмітка всіх секцій сайту; 

CSS3 - кастомний UI-кит (картки, гриди, друкарня, адаптив); 

JavaScript (script.js) – інтерактивні компоненти, фільтри, вікна, робота з формою.

Ключові завдання фронтенду: 

красиво та зручно відмалювати мету 7.40c (герої, складання, тир-лист); 

дати користувачеві інтерактивні інструменти: драфт-хелпер, міні-форум, голосування за героїв/складання; 

реалізувати реєстрацію та профіль через зручну форму; 

вбудувати Twitch та YouTube стриму в загальний дизайн; 

працювати як легкий статичний сайт, який можна легко розгорнути на будь-якому хостингу.

## Структура

Базова структура:

/
├── index.html # Основний HTML (інтерфейс)
├── styles.css # Усі стилі (layout, компоненти)
├── script.js # Клієнтська логіка та інтеграція
└── images/ # Картинки (герої, мета, складання, іконки)

2.1. index.html

Містить повний каркас UI: 

Sidebar (<aside class="td-sidebar">) 

Логотип (TD), назва проекту True Dota, підзаголовок meta & community. 

Навігація по секціям (Головна, Мета, Історія патчів, Складання, Топ героїв, Тир-лист, Драфт-хелпер, Трансляція, Обговорення, Реєстрація, Профіль, Про проект). 

Блоки з поточним патчем та трендами за ролями. 

Компактний віджет користувача («Гість»/статус), кнопка «Увійти/Зареєструватися». 

Topbar (<header class="td-topbar">) 

Назва та підзаголовок (Путівник з мети та обговорень (7.40c)). 

Пошуковий рядок по героям/складанням/темам (планується логіка в JS). 

Основні секції (<section id="section-...">) 

section-home - герой-блок, CTA ("Дивитись мету", "В обговорення"), статуси (у тому, збірок і героїв). 

section-meta - сітка за ролями: Carry, Mid, Offlane, Supports (картки з картинками та списком героїв/особливостей). 

section-patches - таймлайн патчів, що наповнюється через JS. 

section-builds - сітка збірок з фільтрами за ролями, стилем, тривалістю та складністю. 

section-heroes - топ героїв з описами та голосуванням. 

section-tierlist - drag & drop тир-лист (S/A/B/C). 

section-draft - драфт-хелпер (мій пік vs вороги, підказки по драфту). 

section-stream - Twitch + YouTube iframes. 

section-discussions - перелік тем, фільтр по тегам, міні-форум. 

section-register – форма реєстрації. 

section-profile – відображення профілю. 

section-about – короткий опис проекту. 

Модальні вікна 

#newThreadModal - створення нової теми (заголовок, тег, текст). 

#heroDetailsModal — докладна інформація про героя (сильні/слабкі сторони, синергії, контри, приклад складання).

2.2. styles.css

Опис дизайн-системи та загальних правил: 

Layout: 

двоколонна структура: фіксований sidebar + основний контент; 

Компоненти: 

.td-card, .td-btn, .td-chip, .td-tag, .td-list, .td-modal, .td-form і т.д.; 

картки мети та збірок, гриди героїв та тир-листів. 

Кольори та типографіка: 

темна тема, акцентні кольори для тегів та кнопок; 

єдиний стиль заголовків та тексту (H1–H4, body, підписи). 

Анімації та hover-ефекти: 

плавна поява блоків (td-reveal), 

hover на картках та кнопках, 

візуальні підказки для drag & drop зони.

2.3. script.js

Відповідає за інтерактив: 

навігація (підсвічування активного пункту sidebar при скролі); 

мобільне меню (відкриття/закриття сайдбару); 

лічильники (statThreadsCount, statBuildsCount, statHeroesCount); 

заповнення блоку "Герой дня" (heroOfDayCard); 

фільтри збірок (за роллю, стилем, тривалістю, складністю); 

голосування за збірки та героїв (кнопки 👍 та оновлення лічильників); 

ініціалізація тир-листа (drag&drop); 

драфт-хелпер (додавання героїв у «Моя команда» / «Вороги», підказки); 

робота з модалками: 

відкриття/закриття вікна створення теми; 

відкриття модалки героя з докладними даними; 

обробка форми реєстрації: 

збір даних із #registerForm; 

надсилання запиту на backend; 

відображення статусу (#registerStatus); 

оновлення UI профілю (nickname, email, rank, role, about).

## Принцип роботи

Фронтенд влаштований те щоб backend легко можна було замінити (Supabase, інший PHP-сервер, Node тощо.), т.к. вся логіка спілкування винесена до JS.

Основні інтеграційні точки: 

Реєстрація 
Форма #registerForm відправляє дані (nickname, email, password, rank, role, about) на вказаний у script.js endpoint. Очікується JSON-відповідь із результатом реєстрації. 

Профіль 
Після успішної реєстрації фронтенд: 

відображає nickname/email у розділі Профіль, 

оновлює віджет
