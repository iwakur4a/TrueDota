# TrueDota_Backend
Це серверна частина для сайту https://true-dota.bestgastore.site/. Вона відповідає за реєстрацію користувачів, створення їх профілів у базі даних та підв'язку Тг бота.

## Встановлення
Розмістити файли на сервері (Ubuntu/Apache).
Створити в кореневій папці проекту файл .env та вписати туди:
Фрагмент коду
SUPABASE_URL = 'юрл бази даних supabase'
SUPABASE_KEY = 'service_role ключ бази даних'
TG_BOT_TOKEN = 'токен тг бота'
TG_CHAT_ID = 'id бота'

Виконати SQL-запит у консолі Supabase для створення таблиці profiles (поля: id, email, nickname, rank_value, rank_label, role, role_label, about).

## Технології
PHP (cURL) — передача даних між сайтом, БД і Telegram Supabase Auth — керування обліковими записами користувачів PostgreSQL — зберігання ігрових профілів Telegram API — надсилання сервісних повідомлень dotenv — безпечне читання конфіденційних даних

## Файли
server.php - основний файл, приймає дані з фронтенду, реєструє користувача в Auth і записує профіль в таблицю .env - зберігає секретні ключі доступу та налаштування підключення script.js - надсилає асинхронні запити до сервера з браузера
