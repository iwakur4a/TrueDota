# TrueDota_Backend
Это серверная часть для сайта https://true-dota.bestgastore.site/. Она отвечает за регистрацию пользователей, создание их профилей в базе данных и подвязку Тг бота.

## Установка
Разместить файлы на сервере (Ubuntu/Apache).
Создать в корневой папке проекта файл .env и вписать туда:
Фрагмент кода
SUPABASE_URL = 'юрл базы данных supabase'
SUPABASE_KEY = 'service_role ключ базы данных'
TG_BOT_TOKEN = 'токен тг бота'
TG_CHAT_ID = 'id бота'

Выполнить SQL-запрос в консоли Supabase для создания таблицы profiles (поля: id, email, nickname, rank_value, rank_label, role, role_label, about).

## Технологии
PHP (cURL) — передача данных между сайтом, БД и Telegram Supabase Auth — управление учетными записями пользователей PostgreSQL — хранение игровых профилей Telegram API — отправка сервисных уведомлений dotenv — безопасное чтение конфиденциальных данных

## Файлы
server.php — основной файл, принимает данные с фронтенда, регистрирует пользователя в Auth и записывает профиль в таблицу .env — хранит секретные ключи доступа и настройки подключения script.js — отправляет асинхронные запросы к серверу из браузера
