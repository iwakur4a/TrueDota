# TrueDota_bot
Це бот-помічник для сайту https://true-dota.bestgastore.site/. Він потрібний для того, щоб повідомляти в телеграмі про реєстрацію нових користувачів

## Встановлення
Клонувати репо - git clone https://github.com/iwakur4a/TrueDota && git checkout TGBot
Встановити залежність - pip install -r requirements.txt
Створити в кореневій папці проекту файл .env та вписати туди:
TOKEN = 'токен тг бота'
SUPABASE_URL = 'юрл бази даних supabase'
SUPABASE_KEY = 'ключ доступу до бази даних'
Запустити - python run.py

## Бібліотеки
aiogram - API для створення бота
supabase - робота з базою даних
logging - логування дій робота
os, dotenv - завантаження та читання файлу.
asyncio - асинхронність

## Файли
run.py - в ньому ініціалізується бот та підключення до бази даних
handlers.py - потрібен лише для отримання id телеграм акаунту
users_id.py - читання та додавання того самого id в іншу базу даних
database.py – основа. відстежує реєстрацію нових користувачів та відправляє в телеграм чат виходячи з id
