# TrueDota_bot
Это бот-помощник для сайта https://true-dota.bestgastore.site/. Он нужен для того, чтоб уведомлять в телеграме о регистрации новых пользователей

## Установка
Клонировать репо - git clone https://github.com/iwakur4a/TrueDota && git checkout TGBot
Установить зависимости - pip install -r requirements.txt
Создать в корневой папке проекта файл .env и вписать туда:
TOKEN = 'токен тг бота'
SUPABASE_URL = 'юрл базы данных supabase'
SUPABASE_KEY = 'ключ доступа к базе данных'
Запустить - python run.py

## Библиотеки
aiogram - API для создания бота
supabase - работа с базой данных
logging - логирование действий бота
os, dotenv - загрузка и чтение файла .env
asyncio - асинхронность

## Файлы
run.py - в нем инициализируется бот и подключение к базе данных
handlers.py - нужен только для получения id телеграм акаунта
users_id.py - чтение и добавление того самого id в другую базу данных
database.py - основа. отслеживает регистрацию новых пользователей и отправляет в телеграм чат исходя из id
